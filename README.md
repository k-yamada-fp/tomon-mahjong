# 麻雀大会 集計プロトタイプ

## 起動方法

`index.html` をダブルクリックしてブラウザで開いてください。外部サーバーやインストールは不要です。

## 現在できること

- 参加者20名のマスタ管理
- マスタで氏名を変更すると、組み合わせ表・得点入力・結果表へ即時反映
- 第1〜4回戦の組み合わせをプルダウンで変更
- 各卓の編集ボタンから4人分の得点を入力
- 4人の得点合計を確認
- 管理番号順／順位順の結果表示
- 第4回戦終了後に第5回戦を順位順で自動作成
- 第5回戦終了後に第6回戦を順位順で自動作成
- ブラウザ内へ自動保存（localStorage）
- JSONバックアップの保存・復元

## 仮仕様

- 第1〜4回戦には画面確認用の仮組み合わせが入っています。
- 東南西北の担当回数を均等にする検証は実装していません。
- 第5・6回戦は、現段階では上位から4名ずつを `東→南→西→北` の通常表示順に配置します。
- 後ほど「1位を北、2位を西…」という優遇配置へ変更可能です。
- 保存データは開いたPC・ブラウザ内だけにあります。複数端末共有は未対応です。

## Supabase共有保存版

この版は、以下のSupabaseプロジェクトへ接続します。

- Project URL: `https://nxctkqhbwzctwesugyzr.supabase.co`
- Tournament ID: `tomon-mahjong-2026-08-01`

### 動作

- 得点、参加者マスタ、組み合わせ、5・6回戦の席順設定をSupabaseへ共有保存
- 別端末でも同じ大会データを表示
- 5秒ごとに新しい共有データを確認
- localStorageは通信障害時の予備保存として残す
- 画面上部に共有接続・保存状態を表示
- 「共有データ再読込」で手動更新可能

### 注意

- 各端末の表示タブや結果表の並び順は共有しません
- 同時に同じ卓を編集した場合、後から保存した内容が優先されます
